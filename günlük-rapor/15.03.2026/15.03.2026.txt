- Intent çakışmalarını (route/poi/multi/unknown) daha deterministik hale getirmek.

- Gold benchmark ve canlı API testleriyle doğrulamak.

2) Uygulanan Teknik Değişiklikler

2.1 Yeni Modül
- `backend/nlp_concept_resolver.py` (yeni)
  - `normalize_text`, `strip_case_suffix`, `singularize_token`, `morph_candidates`
  - `resolve_poi_concept` (morph+dict -> rule+dict -> opsiyonel bert fallback)
  - `resolve_poi_from_tokens`, `extract_candidates`, `normalize_poi_concept`
  - `resolve_query`, `map_concept_to_osm_queries`

2.2 BERT NLP Akışı
- `backend/bert_nlp_engine.py`
  - POI konsepti için meta dönen akış eklendi: `extract_poi_concept_with_meta`
  - Intent conflict matrix fonksiyonu eklendi ve parse içine bağlandı.
  - Chitchat guard eklendi (merhaba/selam/nasılsın -> unknown).
  - Multi tespiti güçlendirildi:
    - explicit liste ayırma (virgül + "ve")
    - plain liste ayırma ("Moda Bostancı Maltepe gezi planı" gibi)
  - Weak-signal durumda yanlış poi/multi sınıflarına düşmeyi azaltan guard’lar eklendi.
  - OSM-first için timeout-budget/degrade mekanizması eklendi:
    - `ORP_BERT_OSM_TIMEOUT_SEC`
    - `ORP_BERT_OSM_PREFETCH_BUDGET_SEC`
    - `ORP_BERT_OSM_PREFETCH_MAX_QUERIES`
  - Trace’e `intent_conflict_matrix` ve zengin sinyal alanları eklendi.

2.3 Regex Fallback NLP
- `backend/nlp_engine.py`
  - "X'da Y arıyorum/önerir misin" patternleri eklendi.
  - POI çözümleyici entegrasyonu yapıldı; `poi_concept`, `poi_resolution_source/confidence` alanları response’a eklendi.

2.4 API ve Operasyonel Katman
- `backend/app.py`
  - Request middleware eklendi: `X-Request-ID`, `X-Correlation-ID`
  - Response header’larına trace id’ler basılıyor.
  - Basit PII redaction (email/telefon/11 hane kimlik formatları) eklendi.
  - `/api/nlp/parse` response’una `trace_policy` eklendi (request_id/correlation_id/pii_redaction/retention).
  - `/api/search-pois` akışı canonical category + version pin ile güncellendi.
  - `version_profile` response alanı eklendi:
    - `dict_version`, `threshold_profile`, `plan_version`, `cache_token`

2.5 Cache Version Pin
- `backend/cache_manager.py`
  - `POICache` key üretimi `version_token` destekler hale getirildi.
  - Aynı place/category, farklı version token’da cache izolasyonu sağlandı.

2.6 Overpass / Graph Manager
- `backend/graph_manager.py`
  - Geo-bound zorunluluğu eklendi (önce geocode ile merkez bulma).
  - Merkez çözülemezse global sorgu iptal.
  - Kontrollü fallback planı eklendi:
    - A: point radius strict
    - B: point radius relaxed
    - C: place-boundary query
  - Fallback adım limiti route config üzerinden kontrol edildi (`POI_FALLBACK_MAX_STEPS`).
